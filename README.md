A travel poster for **VESPERA**, a place that isn't there: a dusk harbour town
beneath a colossal crystal lighthouse, its golden beam arcing across a deep
teal sky, sailboats with lanterns drifting on mirror-calm water. One impossible
landmark, one golden hour, one place to stay.

Entry for the [make.fun competition](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539)
"The Poster for a Place That Isn't There".

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-built poster
`entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png`.
